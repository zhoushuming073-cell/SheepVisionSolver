# 开发记录

## 2026-10-27

- 保留原有模拟器与测试，核对 `third_party` 实际文件；没有覆盖用户资源。
- REA 6.8.0 的 APK/JADX 路线因本机缺 JDK/JADX 暂未运行；整份 JS 在 1024 MiB 堆上限停止。切出每日挑战的三个相关模块后，REA 静态解析成功；两次证据均已保留。
- 直接从 APK Cocos 资源索引提取经典 1–16 号图案及背景，输出本地素材清单。
- 实现物理屏幕像素截图、负坐标屏幕区域映射、离线截图加载、Tk 手动框选。
- 实现模板识别、卡槽候选识别、保守可点击判定与调试图；在用户截图上离线运行。
- 实现简单三消策略、Win32 鼠标单击、安全区域与频率约束、点击后重新截图验证、JSONL 日志、Tk 操作界面。
- 真实游戏窗口中的单步鼠标点击与三消反馈已验证；连续运行与通关率仍待实验，不将单局局部验证写成真实通关能力。
- 用户提供经典版 888×1428 截图，主牌区离线检出 20 个图案候选、17 个启发式可点击候选；尚无人工作为真值的逐牌标签。
- 点击前增加第二次识别，只有目标牌类型、位置、可点击状态和卡槽均未改变才发出鼠标事件。GUI 单步流程移至后台线程，暂停和停止按钮在识别期间仍可响应。
- 将资源路径与可写数据路径分离，使用 PyInstaller 生成 `dist/SheepVisionSolver.exe` 单文件版本；验证包内包含经典模板、OpenCV 与 pynput 的 Windows 后端，exe 在当前 Windows 桌面可启动并保持运行。
- 现场发现卡槽牌比主牌约大 1.23 倍，原共用缩放导致卡槽漏检并安全停机。增加独立卡槽模板缩放及回归测试，重新打包 exe。在当前游戏窗口执行两次单步点击，卡槽 `8 → 8,8 → 空`，日志均记录成功；消除后的截图已保存。
- v0.2 先测基线：全图识别 P50 约 5.28 秒，旧周期 P50 约 16.93 秒，确认主要瓶颈是重复模板匹配而非截图。借鉴 Screenpipe 的变化门控、ByteTrack 的目标关联思路，未复制第三方代码。
- 为截图缓存 NumPy 像素数组，为模板和牌背缩放建立有界缓存；增加局部识别、目标复核、廉价图像差异检测。OpenCV 限为单线程以减少匹配时的 CPU 峰值。
- 新增可见牌记忆与稳定 ID；待确认点击事务模拟卡槽插入和三消，点击异常不提交状态。自动流程复用一个工作线程；手动识别转为后台任务。GUI 保留校准、单步、暂停、停止和紧急热键。
- 新增无原版素材的合成图像基准及测试。当前 35 项测试通过，单文件 exe 重新构建成功且可启动。实测性能与未验证场景见 `docs/incremental_v02.md`；v0.2 尚未进行真实游戏连续点击实验。
- 修复飞行中的牌与其他牌重叠时过早识别：监测主牌区至卡槽全程的小块图像运动，要求卡槽数量到位并稳定 120 ms；超时不从运动帧重建状态。增加飞行牌、动画暂停与超时回归测试，现有 38 项测试通过。
- 桌面复盘发现卡槽 `15,15,1,1,9` 时基础策略在第五格立即停机，即使一张已确认可点的 9 号牌可能解锁部分遮挡的 15 号牌。加入仅消耗第六格的受限解锁策略，并使手动完整识别重置旧控制器记忆；39 项测试通过。桌面工具的直接点击没有触发 MuMu 牌面变化，仍需通过程序自身的 Win32 控制链路验收。
- 控制程序曾覆盖游戏截图区域，导致预览拍到自身。现在启动和截图前会将控制窗口移出游戏区域。单步实际点击 9 号牌后目标与卡槽无可确认变化，程序未提交预测卡槽并停止；反馈超时已区分“点击未生效”和“动画未稳定”。41 项测试通过，Windows exe 已重新打包并启动验证窗口位置。
- 在桌面控制界面人工选中同一张 9 号牌后再次单步点击，鼠标到达目标，但目标与卡槽仍未变化；游戏窗口聚焦时的直接点击同样没有改变该牌。当前证据不能区分这张牌的实际点击条件和 MuMu 对合成鼠标事件的接收问题，故未改用重复点击或直接提交预测卡槽。
- 游戏重启后重新框选到屏幕原点 `(68, 90)`。Windows 鼠标后端改用 `SendInput`，先确认目标窗口获得焦点，并拒绝点击控制程序自身覆盖的区域。新 exe 在桌面完成 1 次单步和 11 次连续有效点击，日志共 12 次确认；用户界面停止时，待确认操作被中止并要求下次完整同步。该实验同时改变了输入 API 与聚焦流程，不能单独归因于其中一项。飞行牌稳定确认增加至少 150 ms 的观测窗口，相关回归测试 5 次重复通过；全套 43 项测试通过。一次局部冲突后的完整重同步约 8.1 秒，仍需优化。
- 新版 GUI 首次启动时自身窗口覆盖游戏截图区域，导致截图中出现求解器窗口。加入依据物理屏幕坐标将控制窗口移出游戏区域的逻辑和两项测试，当前 41 项测试通过。通过程序单步点击 9 号牌后画面无变化，控制器按超时规则停机，没有提交模拟卡槽。

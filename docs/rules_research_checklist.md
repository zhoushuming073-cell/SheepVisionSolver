# 每日挑战规则研究清单

每一项必须记录日期、游戏版本、设备/平台、关卡日期、复现步骤、原始证据路径、结论等级（事实/假设/未知）。一次观察不足以推出全局生成规律。

- [ ] 牌面图案：所有可见类型、编号、同图案不同状态、资源出处。
- [ ] 牌几何：尺寸、层级、区域坐标、重叠与可点击边界。
- [ ] 遮挡：部分覆盖是否可点；多张遮挡的移除顺序；动画期间判定。
- [ ] 卡槽：容量、插入位置、消除时机、满槽与三消同一步的先后顺序。
- [ ] 主牌区：初始布局、剩余牌显露、可点击状态。
- [ ] 辅助区：顺序、可见性、是否与主区共用三消规则。
- [ ] 盲盒区：数量可见性、翻牌时机、下一张是否开局固定。
- [ ] 道具：触发条件、效果、次数、对胜负判定的影响。
- [ ] 重开实验：同日同关重开后的布局、牌型和隐藏序列是否一致。
- [ ] 数量约束：总牌数、各类型数量、是否均为 3 的倍数。
- [ ] 底牌生成：开局确定或运行时生成；是否受点击顺序影响。
- [ ] 无道具可解性：重复样本与反例；不能从单次成功推出保证可解。
- [ ] 胜利/失败：剩余牌、卡槽、无合法动作、弹窗/动画的准确判定。
- [ ] 每日挑战与其他模式的规则差异。
